# 学校の行事予定・時間割を Google カレンダーへ（ひな形）

学校の月別「行事予定表」と「時間割」から、職員が自分の Google カレンダーに予定を入れられるウェブページを作るためのひな形です。名古屋市立汐路中学校で作ったページをもとにしています。

## できること

- **行事予定のページ**
  - 行事・会議・提出の予定を月ごとに表示します。
  - 1件ずつの「追加」、まとめての .ics 保存、Googleログインでの直接登録ができます。
  - 「購読」ボタンで、学校の予定をまとめて表示できます。
- **時間割のページ**
  - 先生が名前を選ぶと、その先生の授業が1日ずつ表示されます。
  - A帯・B帯などの時刻、振替、行事で授業がないコマを反映します。
  - 登録方法は、ログイン登録・購読・.ics 保存の3つです。

このひな形には、架空の学校の見本データが入っています。

## 自分の学校用に作る手順

### 1. ひな形をコピーする

1. このページの右上の緑のボタン「Use this template」を押し、「Create a new repository」を選びます。
2. Repository name に名前を入れます（例：`marumaru-calendar`）。
3. 時間割には先生の名前が入るので、**「Private」を選ぶ**のがおすすめです。
4. 「Create repository」を押します。

### 2. Claude Code で、自分の学校のデータに差し替える

1. [claude.ai/code](https://claude.ai/code) を開き、1. で作ったリポジトリを選びます。
2. 次の3つを添付します。
   - 行事予定表（PDF）
   - 時間割（Excel）
   - 日課表（各時間の開始・終了時刻）
3. 次のように頼みます。

   > CLAUDE.md の手順で、学校名を「〇〇市立〇〇中学校」にして、添付の行事予定と時間割に差し替えて。

   Claude が、設定・行事予定・日ごとの振替・時間割のデータを作ります。

### 3. surge.sh で公開する

1. Claude に「surge.sh に `〇〇-gyoji.surge.sh` で公開して」と頼みます。名前は、学校が分かる好きな名前にします。
2. surge のアカウントは、初回だけ作る必要があります。手順は Claude が案内します（メールアドレスとパスワードを決めるだけです）。
3. 公開した URL を職員に配ります。

### 4. （必要なら）Googleログインでの直接登録を使えるようにする

ログイン登録には、学校で用意する Google アカウントの「OAuth クライアント ID」が必要です。

用意しない場合も、「追加」「.ics 保存」「購読」は使えます。ログインのボタンが出ないだけです。手順は Claude に「Googleログインの設定方法を教えて」と頼めば、画面ごとに案内します。

## 毎月の更新

1. 新しい行事予定表（PDF）を Claude に渡し、「来月分を追加して公開して」と頼みます。
2. 購読している人のカレンダーは、半日〜1日で自動的に新しくなります。

## 注意

- 公開したページは、URL を知っている人なら誰でも見られます。載せてよい内容か、学校で確認してください。
- 自治体のアカウントでは、Googleログインが市の設定で止められていることがあります。そのときは「購読」か「.ics 保存」を使ってください。
