行事予定カレンダー登録

このページ（）は、の職員が、学校の行事予定や授業の時間割を自分の Google カレンダーに登録するための道具です。

1. 使う情報

「Googleでログイン」を押して許可した場合に限り、次の情報を使います。

  • カレンダーの一覧（登録先を選ぶため）
  • 登録する日の予定の名前（同じ予定を二重に登録しないため）
  • 予定の登録・入れ直しと、「 行事」などのカレンダーの作成（利用者が選んだときだけ）

2. 情報の扱い

  • すべての処理は、利用者のブラウザと Google の間だけで行います。運営者のサーバーに情報を送ったり、保存したりすることはありません。
  • ログインの許可（アクセストークン）は、ページを開いている間だけブラウザの中に置き、ページを閉じると消えます。
  • 集めた情報を第三者に渡すことはありません。広告や分析には使いません。

3. 許可の取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも許可を取り消せます。

4. Google API の利用について

このページが Google API から受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。
