カレンダーを「購読」する

ボタンを押して「追加」を押すだけで、学校の予定がまとめて表示されます。あとから増えた予定も、自動で表示されます。

すべて（行事・会議・提出） 行事だけ 会議だけ 提出だけ
ボタンでうまくいかないとき・注意
  1. パソコンで Googleカレンダーを開き、左の「他のカレンダー」の「＋」→「URL で追加」を押します。
  2. 下のどれかの URL をコピーして貼り付け、「カレンダーを追加」を押します。
すべて行事会議提出

・購読したカレンダーは見るだけで、予定の書き換えはできません。
・予定の変更が反映されるまで、半日〜1日ほどかかります。
・スマホのカレンダーアプリでは追加できません。一度パソコンで追加すると、スマホにも表示されます（表示されないときは、アプリの設定でそのカレンダーの「同期」をオンにします）。
・このページで同じ予定を登録済みの場合は、予定が2つずつ表示されます。

使い方

Googleにログインして、まとめて登録するとき（おすすめ・スマホもOK）

  1. 月を切り替えながら、入れたい予定にチェックを付けます。
  2. 「Googleでログイン」を押し、自分のアカウントを選びます。
  3. 初めてのときだけ「このアプリは Google で確認されていません」と出ます。「詳細」→「（安全ではないページ）に移動」を押し、カレンダーへのアクセスにすべてチェックを入れて「続行」を押します。
  4. 種類ごとに登録先のカレンダーを選び、「カレンダーに登録する」を押します。

同じ日に同じ名前の予定がすでにあれば、二重には登録しません。
LINE やメールのアプリから開くとログインできないことがあります。そのときは Safari や Chrome で開き直してください。

1件ずつ入れるとき

  1. 予定の右にある「追加」を押します。
  2. Googleカレンダーの登録画面が開くので、右上の「保存」を押します。

まとめて入れるとき（パソコンで）

  1. 月を切り替えながら、入れたい予定にチェックを付けます。
  2. 「.ics ファイルで保存」を押します。ファイルがダウンロードされます。
  3. 下のボタンで、Googleカレンダーの読み込み画面を開きます。 Googleカレンダーの読み込み画面を開く （自分で開くときは、Googleカレンダー右上の歯車 →「設定」→ 左の「インポート/エクスポート」）
  4. 「パソコンからファイルを選択」で、保存した .ics ファイルを選びます。
  5. 「カレンダーに追加」で入れ先のカレンダーを選び、「インポート」を押します。

.ics ファイルをダブルクリックすると Outlook が開いてしまいます。必ず上の手順で読み込んでください。
会議と行事を別のカレンダーに入れたいときは、「会議だけ」「行事だけ」で選んで、別々に保存・読み込みをします。
同じファイルを同じカレンダーに2回読み込んでも、予定が二重になることはありません。

終了時刻が決まっていない会議は、仮に1時間で入れています。「選ぶ」ボタンは表示中の月に効きます。
